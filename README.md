# dtk-pbi — release

Questo repository contiene solo gli installer di **dtk-pbi** per Windows e il file
`latest.json` con cui l'app si aggiorna da sola. Non contiene codice.

dtk-pbi trasferisce le tabelle di un modello Power BI in uno schema Open SQL di SAP
Datasphere, con una view nel Data Builder per tabella. Funziona insieme a `dtk`, che si
installa seguendo il README del repository del toolkit, e a Power BI Desktop. Senza `dtk`
e senza le credenziali di un tenant l'app non fa niente.

Segnalazioni e richieste non si aprono qui.
